# PDF Crop Studio

Мобильный браузерный инструмент для быстрого открытия PDF, выбора области страницы и экспорта выбранного фрагмента в изображение высокого разрешения.

## Возможности

- открытие PDF локально в браузере;
- навигация по страницам;
- масштабирование и перемещение страницы;
- выбор и изменение области кадрирования;
- экспорт в JPG, PNG и WebP;
- настройка ширины выходного изображения;
- оптимизированный рендер только выбранной области;
- адаптивный интерфейс для смартфонов и планшетов;
- автономная версия без внешних зависимостей.

## Запуск

### Обычная версия

Откройте `index.html` в современном браузере. Для корректной загрузки модулей рекомендуется локальный HTTP-сервер:

```bash
python -m http.server 8080
```

Затем откройте `http://localhost:8080`.

### Автономная версия

Откройте `PDF_Crop_Studio_Standalone.html` напрямую в браузере. Все зависимости встроены в файл.

## Структура

- `index.html` — основная компактная версия с PDF.js через CDN;
- `PDF_Crop_Studio_Standalone.html` — автономная сборка;
- `README.md` — описание проекта.
